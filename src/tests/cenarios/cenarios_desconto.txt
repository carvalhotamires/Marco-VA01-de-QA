====================================================================
DOCUMENTAÇÃO DE CENÁRIOS DE TESTE - TECH UNIDIASUP
História de Usuário: Cálculo de Descontos Progressivos no E-Commerce
Função Alvo: calcular_desconto(valor_compra, tipo_cliente)
====================================================================

CRITÉRIOS DE ACEITE (REGRAS DE NEGÓCIO):
1. Compras < R$ 100,00: 0% de desconto base.
2. Compras >= R$ 100,00 e < R$ 500,00: 10% de desconto base.
3. Compras >= R$ 500,00: 20% de desconto base.
4. tipo_cliente == "VIP" (case-insensitive: maiúsculo/minúsculo): +5% extras sobre a base.
   tipo_cliente == "COMUM": sem acréscimo (0% extra).
5. Regra de Teto: valor máximo do desconto é R$ 200,00.

--------------------------------------------------------------------
TABELA DE CENÁRIOS DE TESTE (TÉCNICA DE PARTIÇÃO DE EQUIVALÊNCIA E VALOR LIMITE):
--------------------------------------------------------------------

Cenário 1: Compra menor que R$ 100 com cliente COMUM (0% base + 0% extra = 0%)
- Entrada: valor_compra = 50.00, tipo_cliente = "COMUM"
- Esperado: R$ 0.00

Cenário 2: Limite superior da faixa sem desconto base com cliente COMUM (99.99)
- Entrada: valor_compra = 99.99, tipo_cliente = "COMUM"
- Esperado: R$ 0.00

Cenário 3: Compra menor que R$ 100 com cliente VIP (0% base + 5% extra = 5%)
- Entrada: valor_compra = 80.00, tipo_cliente = "VIP"
- Esperado: R$ 4.00 (5% de 80.00)

Cenário 4: Limite exato de R$ 100,00 com cliente COMUM (10% base) [PONTO CRÍTICO / BUG JR]
- Entrada: valor_compra = 100.00, tipo_cliente = "COMUM"
- Esperado: R$ 10.00 (10% de 100.00)
- Nota: O código do Dev Jr. usa `> 100`, ignorando R$ 100,00!

Cenário 5: Limite exato de R$ 100,00 com cliente VIP (10% base + 5% extra = 15%) [BUG JR]
- Entrada: valor_compra = 100.00, tipo_cliente = "VIP"
- Esperado: R$ 15.00 (15% de 100.00)

Cenário 6: Faixa intermediária (R$ 300,00) com cliente COMUM (o que o Jr. testou de cabeça)
- Entrada: valor_compra = 300.00, tipo_cliente = "COMUM"
- Esperado: R$ 30.00 (10% de 300.00)

Cenário 7: Faixa intermediária com cliente VIP (10% base + 5% extra = 15%)
- Entrada: valor_compra = 300.00, tipo_cliente = "VIP"
- Esperado: R$ 45.00 (15% de 300.00)

Cenário 8: Limite superior da faixa de 10% (R$ 499,99) com cliente COMUM
- Entrada: valor_compra = 499.99, tipo_cliente = "COMUM"
- Esperado: R$ 50.00 (10% de 499.99 = 49.999 -> arredondado para 50.00)

Cenário 9: Limite inferior da faixa de 20% (R$ 500,00) com cliente COMUM
- Entrada: valor_compra = 500.00, tipo_cliente = "COMUM"
- Esperado: R$ 100.00 (20% de 500.00)

Cenário 10: Limite inferior da faixa de 20% (R$ 500,00) com cliente VIP (20% + 5% = 25%)
- Entrada: valor_compra = 500.00, tipo_cliente = "VIP"
- Esperado: R$ 125.00 (25% de 500.00)

Cenário 11: Compra alta de R$ 800,00 com cliente COMUM (20%)
- Entrada: valor_compra = 800.00, tipo_cliente = "COMUM"
- Esperado: R$ 160.00 (20% de 800.00)

Cenário 12: VIP com letras minúsculas "vip" [PONTO CRÍTICO / BUG JR]
- Entrada: valor_compra = 200.00, tipo_cliente = "vip"
- Esperado: R$ 30.00 (15% de 200.00)
- Nota: O código do Dev Jr. compara estritamente com `"VIP"`.

Cenário 13: VIP com letras mistas "Vip" [BUG JR]
- Entrada: valor_compra = 200.00, tipo_cliente = "Vip"
- Esperado: R$ 30.00 (15% de 200.00)

Cenário 14: Regra do Teto - Desconto que ultrapassaria R$ 200,00 com cliente VIP
- Entrada: valor_compra = 1000.00, tipo_cliente = "VIP"
- Cálculo teórico: 25% de 1000.00 = R$ 250.00
- Esperado: R$ 200.00 (limitado pelo teto)

Cenário 15: Regra do Teto - Desconto que ultrapassaria R$ 200,00 com cliente COMUM
- Entrada: valor_compra = 1500.00, tipo_cliente = "COMUM"
- Cálculo teórico: 20% de 1500.00 = R$ 300.00
- Esperado: R$ 200.00 (limitado pelo teto)

Cenário 16: Valor exatamente no teto (R$ 800,00 VIP -> 25% = 200.00)
- Entrada: valor_compra = 800.00, tipo_cliente = "VIP"
- Esperado: R$ 200.00
